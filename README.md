# Política de Privacidade — Tax Innovation

Projeto independente da página de Política de Privacidade e Proteção de Dados Pessoais da Tax Innovation.

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Publicação

```bash
npm run build
```

O projeto usa exportação estática do Next.js. Os arquivos prontos para hospedagem serão gerados na pasta `out/`.

Domínio planejado: `politica-privacidade.taxinnovation.com.br`.
